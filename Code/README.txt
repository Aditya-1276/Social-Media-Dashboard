In order to run the code:
1. Install VS Code from code.visualstudio.com
2. Download and install Python from python.org. During installation, check "Add Python to PATH" before clicking install
3.  Install the Python and Jupyter extensions in VS Code

Open VS Code → click the Extensions icon on the left sidebar (or Ctrl+Shift+X) → search "Python" → install the one by Microsoft → search "Jupyter" → install the one by Microsoft.

4. Open the "LRZ Project" folder in VS code
5. Update the "common_path" variable to wherever you've stored the folder
6. Run the code

If you do end up moving the contents of the folder around, especially the data folder and it's contents, adjust the paths in the "from_xlsx" and "to_xlsx" functions accordingly.
